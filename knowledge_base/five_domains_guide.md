# 《3-6 岁儿童学习与发展指南》五大领域要点速查

> 本文件是"童心AI绘本馆"提示词工程的知识库底座。
> 依据教育部《3-6 岁儿童学习与发展指南》（2012）整理，按领域 × 年龄段列出典型目标，供 StoryGenerator / ActivityPlanner 在生成内容时对齐。

---

## 一、健康领域

### 小班 3-4 岁
1. 能正常走路、跑步，动作较协调。
2. 能用勺子自己吃饭，不撒饭。
3. 在成人提醒下饭前洗手、便后洗手。
4. 能在提醒下早睡早起，白天午睡 2 小时左右。
5. 不害怕看医生、吃药。
6. 遇到危险（如火、开水）知道躲开到大人身边。

### 中班 4-5 岁
1. 能连续跑 200 米左右，能双脚交替跳。
2. 能用筷子夹起大块食物。
3. 能自己穿脱套头衫、扣纽扣。
4. 能连续午睡 1.5-2 小时。
5. 知道不把异物放入口、鼻、耳中。
6. 能在帮助下避开常见的危险（不爬高、不玩尖锐物品）。

### 大班 5-6 岁
1. 能连续跑约 400 米，能跳绳、拍球。
2. 能熟练使用筷子，能自己系鞋带。
3. 能根据冷热增减衣物。
4. 养成每天按时睡觉、起床的习惯。
5. 能主动避让危险，知道简单的求助方式（找老师、打 110）。
6. 知道保护牙齿、认真刷牙。

## 二、语言领域

### 小班 3-4 岁
1. 能听懂简短的普通话指令。
2. 能说简单的主谓宾句子（"我要喝水"）。
3. 愿意听短小的儿歌、故事。
4. 能跟着老师念重复的儿歌或童谣。
5. 能指认常见物品的名称。

### 中班 4-5 岁
1. 能较连贯地讲述一件小事（1-2 句）。
2. 能听懂连续 2-3 步的指令。
3. 喜欢跟读韵律感强的儿歌、古诗。
4. 能主动向老师或同伴提问。
5. 能感受故事中角色的情绪（开心、难过）。
6. 愿意在集体面前说话（声音不大也行）。

### 大班 5-6 岁
1. 能连贯、清楚地讲述一段经历或故事。
2. 能根据故事画面预测接下来发生什么。
3. 能独立念完一首简单的儿歌或短诗。
4. 对文字符号感兴趣（认路牌、认自己的名字）。
5. 能礼貌地用"请""谢谢""对不起"。
6. 愿意把自己喜欢的书讲给别人听。

## 三、社会领域

### 小班 3-4 岁
1. 能和熟悉的同伴一起玩（平行游戏为主）。
2. 能在提醒下问好、说再见。
3. 能感觉到自己被喜欢、被接纳。
4. 遇到困难会找老师。
5. 知道玩具是大家的，不能独占。

### 中班 4-5 岁
1. 喜欢和同伴一起玩，能进行简单的合作游戏。
2. 愿意把自己的玩具借给同伴。
3. 能识别别人的情绪（"他在哭，他难过"）。
4. 能在提醒下遵守游戏规则。
5. 知道自己是幼儿园的一员，喜欢自己的班级。
6. 遇到冲突会找老师帮忙，而不是直接动手。

### 大班 5-6 岁
1. 能和同伴分工合作完成一件事。
2. 能自己解决小冲突（轮流、石头剪刀布）。
3. 能关心同伴（"你没事吧？"）。
4. 知道自己的优点，也能说出同伴的优点。
5. 能遵守基本规则（排队、等待）。
6. 对小学有向往，愿意为上小学做准备。

---

## 四、科学领域

### 小班 3-4 岁
1. 喜欢摸一摸、看一看身边的物品。
2. 能分辨常见的颜色（红、黄、蓝）。
3. 能分辨大小、多少。
4. 对身边的小动物、植物感兴趣。
5. 能数 1-3 个物品。

### 中班 4-5 岁
1. 能观察并说出事物的明显特征（颜色、形状）。
2. 能数 1-10 个物品。
3. 能分辨上下、前后、里外。
4. 对天气变化、动植物生长好奇。
5. 能按一个简单的标准给物品分类（按颜色、按形状）。

### 大班 5-6 岁
1. 能连续数数到 20，理解 10 以内的数量。
2. 能分辨左右（以自身为中心）。
3. 能观察并记录简单的自然现象（植物生长、天气）。
4. 对常见的物理现象好奇（影子、沉浮）。
5. 能提出简单的问题（"为什么会下雨？"）。
6. 能与同伴分享自己的发现。

---

## 五、艺术领域

### 小班 3-4 岁
1. 喜欢听音乐、跟着简单的节奏拍手。
2. 能用蜡笔随意涂画。
3. 愿意模仿老师做简单的律动。
4. 能感受鲜艳颜色的美。

### 中班 4-5 岁
1. 能跟着音乐做简单的舞蹈动作。
2. 能用画、捏泥表现自己见过的东西。
3. 能分辨明显的高低、快慢节奏。
4. 愿意把自己的作品给别人看。

### 大班 5-6 岁
1. 能使用多种材料（画笔、剪刀、黏土）进行创作。
2. 能给故事配一幅画或编一段动作。
3. 能感受不同风格的音乐（欢快、安静）。
4. 愿意在集体面前表演（唱歌、律动）。
5. 能说出自己喜欢哪件艺术品、为什么。

## 使用说明（给提示词）

- StoryGenerator 在生成故事时，应根据 age_group 自动对齐上表中对应年龄段的语言 / 社会目标难度。
- ActivityPlanner 在写 goals 时，应直接引用上表中的 1-3 条作为依据，避免空泛目标。
- EvaluationEngine 在写观察评语时，可参照上表判断幼儿表现"达到 / 接近 / 暂未达到"典型目标。
