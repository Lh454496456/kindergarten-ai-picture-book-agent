# 第二步：配置 4 个工作流

每个工作流都是 3 个节点：开始节点 → 大模型节点 → 结束节点。

## 工作流 1：wf_story_generator（绘本生成）

- 输入：theme(String)、age_group(String)、domain_tags(Array)
- 系统提示词：复制 `prompts/wf_story_generator.md`
- 输出：story_json

## 工作流 2：wf_dialogue（幼儿对话）

- 输入：story_title、character_name、plot_summary、age_group、child_message
- 系统提示词：复制 `prompts/wf_dialogue.md`
- 输出：reply_json

## 工作流 3：wf_activity_planner（活动方案）

- 输入：story_json、age_group
- 系统提示词：复制 `prompts/wf_activity_planner.md`
- 输出：plan_json

## 工作流 4：wf_observation（观察记录）

- 输入：observation_log(Array)、child_label(String)
- 系统提示词：复制 `prompts/wf_observation.md`
- 输出：observation_json

## 挂载到 Bot

Bot 编辑页 → 技能 → 工作流 → 添加这 4 个工作流 → 发布。
